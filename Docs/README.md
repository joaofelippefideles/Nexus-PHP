# Nexus Tech — Documentação (Docs)

Esta pasta reúne todos os documentos gerados durante o desenvolvimento do projeto Nexus Tech:

- Relatórios;
- Análises;
- Planejamentos;
- Checklists;
- Notas técnicas;
- Qualquer outro tipo de arquivo `.md` produzido ao longo do projeto.

## Estrutura sugerida

```
Docs/
├── relatorios/
├── analises/
└── ... (demais categorias conforme necessário)
```

## Observação

Os documentos de planejamento/roadmap do projeto estão centralizados no `README.md` da raiz do projeto. Esta pasta é destinada a arquivos de apoio gerados durante as Sprints.
